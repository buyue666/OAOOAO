# Creative tools on demand

The feature center is a directory of tools grouped by purpose. A card opens the tool directly; users no longer have to enable or disable it. Search and category filters stay within the directory. Release information is secondary, inside a collapsed section.

The directory imports only lightweight metadata and small preview images. Navigation does not prefetch tool routes. Each tool retains its dynamic client entry; reference catalogs, editors and 3D resources load when that tool is opened. Personal project summaries are requested only by pages that use them, and recent drama projects use a four-item summary query.

Legacy installation flags remain readable for older clients. They are preferences, not authorization. Login, account isolation, team project access, model availability and billing checks remain enforced. Version preferences can be saved independently of legacy installation state. Existing preferences are preserved, including a user's pinned editor version.

The public distribution retains the original director 0.1 implementation and its reviewed resources. Private tools, source assets and production settings are not part of this change.

Validation covers direct entry with all legacy flags disabled, guest and loading gates, account switching with delayed responses, team scope, server-confirmed version preferences, route-dependent project loading and directory filtering. Browser checks cover themes, narrow layouts and network timing. No paid generation requests are needed for this validation.
