# Creative tool presentation

Creative tools use one navigation entry and a categorized directory with direct access. Cards reveal an explicit action on hover or keyboard focus and keep the action visible on touch devices.

Administrators can control availability and configure titles, descriptions, ordering, images, videos, comparison and carousel timing in the Creative tools presentation module. Uploads use the configured object storage and bounded, sniffed media types. Existing work remains readable after a tool closes; new tool submissions enforce availability on the server.

Media stays lazy and pauses when hidden. Reduced-motion preferences disable automatic carousel and video behavior. Tool implementations and reference catalogs remain behind their existing dynamic entry points. Director manual version preferences remain intact.

Validation: focused interface and authorization tests, isolated synthetic backend tests, frontend/backend typechecks and the unchanged 31-file public boundary policy. No paid generation is part of these checks.
