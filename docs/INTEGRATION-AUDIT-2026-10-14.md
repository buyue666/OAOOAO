# 运营功能核对 · 2026-10-14

本次从管理员实际配置流程核对前端入口、API、数据库写入和最终使用结果。测试使用合成账户、合成密钥及临时 PostgreSQL schema；不向真实收款渠道付款，不调用真实公众号，不修改客户积分。通过以下检查不代表所有外部服务都已验收。

## 本次修复

| 功能 | 原问题 | 当前行为 |
| --- | --- | --- |
| 易支付 | 支付协议未实现，配置界面只支持人工收款。 | 可选择 V1 MD5 / V2 RSA，填写对应凭证；签名通知校验商户、订单、金额和交易号后幂等到账。 |
| 支付配置 | 固定字段不能配置不同渠道；空白密钥容易引起误解。 | 按协议展示字段，说明必填项、回调地址及密钥保留/清除规则；未实现渠道明确不可用。 |
| 订单操作 | 非人工订单也显示人工完成按钮。 | 只有人工订单能人工确认收款；易支付由验证通过的通知结算。 |
| 外部退款 | 易支付订单没有退款登记入口。 | 已核实支付可先预留积分，通过原渠道退款后确认登记；积分不足时阻止预留。本站不自动转账。 |
| 微信扫码 | 服务端是不可用占位接口；前端消费授权时可能因异步状态变化而忽略结果。 | 公众号参数二维码、安全模式回调、浏览器绑定和一次性消费；已有账户须密码验证后绑定，不自动合并用户。 |
| 注册规则 | 新扫码注册路径可能绕过邮箱验证策略。 | 开启邮箱验证注册时，先注册验证邮箱并绑定；未绑定微信不会直接创建账户。 |
| 套餐功能 | `features` 是不执行鉴权的自由文本标签。 | 五项中文多选保存为 `allowedGenerationKinds`；后端在创建任务和扣费前执行限制，包括创作助手与成片合成。 |
| 审计筛选 | 预置筛选仍使用旧动作名称。 | 默认提供当前后端动作，并用中文显示动作、角色及对象类型。 |
| 后台文案 | 支付渠道、邀请/治理状态、统计类型、上线检查使用原始英文。 | 已知业务状态显示中文；模型名称、技术协议名及实际标识保留，便于核对。 |
| 邀请奖励 | 前端提供服务端不支持的套餐体验和自动风险冻结。 | 奖励类型仅提供积分或不奖励；说明自动风险评分暂未接通。 |
| 邮件设置 | 脱敏后的空密码被误认为未配置。 | 按服务端的凭证存在标记显示保存状态；只读标记不会作为密码提交，发送协议明确为 SMTP。 |
| 治理案件 | 提示声称会自动处理作品并通知相关用户，实际仅登记结论。 | 明确区分案件结论与作品下架操作，不声称自动通知；处理后关闭过时详情。 |

## 权益多选规则

- 文本生成、图片生成、视频生成、音频生成、成片合成分别控制新任务。
- 总开关「套餐权益限制」开启后，使用当前有效套餐；无有效套餐时使用默认权益方案。
- 创作助手规划及生成步骤也经过相同检查。仅开放图片、未开放文本时，文本规划不会绕过限制。
- 旧方案未设置该字段时默认全部允许，避免升级意外停用现有能力；显式取消全部勾选会禁止以上新任务。
- 不影响查看已有项目、资产和历史记录。已创建任务的幂等重试不会重复收费；新任务仍受积分、每日限额和实际模型配置约束。
- 历史 `features` 标签仅作为兼容记录保留，不作为鉴权依据。

## 仍需配置或尚未支持

| 能力 | 当前边界 |
| --- | --- |
| 真实易支付商户 | 未预置网关、商户或密钥。需运营者填写，并验证付款、通知、到账、异常及退款。配置完整不等于实测成功。 |
| 真实微信公众号 | 需要参数二维码接口权限、服务器 IP 白名单和安全模式回调。此实现是公众号流程，不是微信开放平台网站 OAuth。 |
| 直接支付宝、微信支付、Stripe | 尚未实现。易支付聚合收款不等于平台直接支付协议。 |
| 创作对象存储 | 当前生成媒体落在服务器持久化目录；S3 设置仅有连接检查，尚无创作素材写入适配。 |
| 剪映官方草稿格式 | 接口明确返回不可用；不能将普通工程数据当作可导入的剪映草稿。 |
| 自动邀请风险评分 | 未实现。可配置最低付费门槛、冷静期和奖励上限。 |
| 多因素认证 | 未实现。 |
| 任意可执行技能、视觉聊天和其他供应商协议 | 当前是可复用指令技能与已实现适配器；不能把配置字段视为执行能力。 |

## 验证证据与限制

- 前端统一验收涵盖支付草稿保留、密钥不回显、权限分组、中文权益多选、扫码状态控制及原有画布、公告、签到、积分超市等回归。
- `backend/tests/payment-epay.test.ts`：两种协议、并发通知、金额与商户不匹配、交易复用、关闭与密钥轮换、超时订单、事务回滚及退款后通知。
- `backend/tests/wechat.test.ts`：官方 AES 向量、回调签名、跨浏览器隔离、并发消费、现有账户绑定、邮箱策略、停用与过期、配置遮盖、审计失败回滚；取消关注后保留原账户身份。
- `backend/tests/entitlement-capabilities.test.ts`：方案字段验证、默认/有效套餐选择、禁止直接及创作助手任务、扣费前拒绝和旧任务幂等返回；并发撤销套餐时，收费及免费新任务均等待用户锁后重新读取权益，停用账户也无法提交。
- 新迁移只添加支付尝试及微信授权/绑定表；前 12 个迁移不变，不自动启用支付、不创建真实微信绑定，也不回填客户数据。
- 浏览器验收使用隔离服务，核对保存后重载与数据库结果。真实支付、公众号、邮件或模型消费必须另外完成外部联调。
