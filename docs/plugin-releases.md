# 插件发布

插件版本独立于 OAO 应用版本。安装状态是账户的工具开关；实现随网站发布更新，无需卸载重装。

每次改动插件实现，更新 `lib/studio/creative-plugin-releases.json` 中对应版本、发布日期和中文更新记录。修复升补丁位，新增功能升次版本，破坏性变更升主版本；不为未改动插件虚增版本。

完成代码与内嵌导演台构建后，运行 `npm run release:plugins`，再运行 `npm run build`。发布锁记录实现文件摘要；实现变化却未升级版本时，构建必须失败。先确认正确版本，不能仅重写摘要绕过检查。

插件目录和安装页统一读取发布清单。更新文案同时维护英文翻译。AI 换装及相关私有实现、部署配置和发布记录继续保留在私有部署目录。
